About CMFPU

Chat Messenger For Private Use

A peer-to-peer end-to-end encrypted messenger that runs entirely in your browser. No accounts. No servers in the message path. Public STUN servers (Google, Cloudflare) are used only to discover network addresses for the WebRTC handshake; they never see message content.
